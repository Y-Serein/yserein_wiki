# 文件校验与升级

## 核对下载

下载页中的版本、文件名、大小和 SHA-256 必须对应同一个文件。展开“文件信息与 SHA-256”可复制完整摘要。Windows 文件属性中也可确认实际文件大小；不要仅凭相似的文件名判断版本。

在 PowerShell 中可使用 `Get-FileHash -Algorithm SHA256`，其后指定实际下载文件路径，再与页面中的完整摘要比较。摘要不一致时停止运行，重新从明确的来源获取文件。

## 安装与更新

- Windows x64 安装器不等于 Linux 或 macOS 安装包。
- Serein 升级前保存并备份 Vault；Swarm 更新前结束现场作业。
- Scope 更新组件前停止连接与任务、关闭工作区并卸载旧版运行实例，再导入匹配版本。
- 下载和安装免费不代表所有服务或作业权限免费；账户授权以实际产品要求为准。

## 失败与恢复

下载失败可重新获取文件，不必删除已有文档或配置。安装失败记录具体系统提示并联系支持。不要关闭系统安全检查来掩盖来源或摘要异常；校验值不能替代 Windows 发布者签名。
