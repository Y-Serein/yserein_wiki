# 五分钟上手

## 认识工作台

- 左侧 Activity Rail 选择全局功能和组件。
- 中央工作区显示当前组件内容；上方标签用于切换工作区。
- Context 放当前任务的操作，Inspector 放选中对象与测量信息，Output 放结果和日志。这些面板由宿主管理，可按需要显示。
- 组件库中的控件由宿主入口加入当前画布。画布支持组件规定的布局编辑与恢复。

## 用 Serial Scope 观察数值

1. 打开 **Serial Scope** 工作区。
2. 在 Context 中扫描串口，选择端口和波特率，选择 **Delimited numeric** 解析引擎。
3. 连接设备；如果设备按行发送 `1.2,3.4,5.6` 这样的逗号分隔数值，工作区会显示通道和波形。
4. 要查看原始文本，切换到 **Raw text** 引擎；需要发送命令时在终端选择合适的行结束方式。
5. 结束时先断开连接，再关闭工作区或卸载组件。

数值行必须由设备实际发送，并带换行结束符；上面的内容只是输入格式示例。串口打开失败时，检查端口是否被其他工作区或其他程序占用。

## 安装组件

打开组件管理，选择导入文件或目录，再加载并打开工作区。导入、加载、打开、关闭工作区、卸载和移除是不同操作。正在使用的组件需要先关闭工作区、停止任务，才能卸载或移除。对同一组件 ID 的新版本，按界面提示选择替换或保留并列安装项。

下一步可阅读[用户手册](user-guide.md)、[组件说明](components.md)或[常见问题](faq.md)。
