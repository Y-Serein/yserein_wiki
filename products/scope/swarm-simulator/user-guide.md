# Serein Scope · Swarm 模拟组件用户使用手册

在 Serein Scope 中生成模拟机群、预览箱式舞步与导入舞步，并与 YSerein Swarm 地面站进行操作联调。

文档版本：1.0 · 2026 年 10 月

- 适用组件：组件库中的 YSerein Swarm Simulator。
- 本手册对应 Scope 内嵌模拟组件；独立模拟器安装器与 Scope 组件包分别管理。
- 模拟显示不代表真实设备状态。联调网络中应只包含允许受控的模拟设备。

## 01 快速上手：生成并播放 12 台模拟机

首次使用可从 3 行 × 4 列的小编队开始，熟悉界面和播放方式。

1. 启动 Serein Scope，从组件库找到“YSerein Swarm Simulator”，加载并打开工作区。
2. 在左侧“编队会话 → 网格编队”中设置行数 3、列数 4，按需要设置间距，点击“一键生成”。
3. 在右侧“机群属性”与中央画面确认出现 12 台模拟机。
4. 将“播放来源”设为“箱式舞步”，箱子行列保持 3 × 4，确认界面显示已就绪。
5. 点击“播放舞步”，观察时间、运动阶段和模拟机位置；需要暂停时再次点击播放按钮。
6. 点击“停止”回到起始时刻。需要重新创建时，点击“清除全部模拟机”并确认，等待对象归零后再生成。

### 第一次使用先认清

| 操作 | 作用 |
| --- | --- |
| 一键生成 | 创建模拟设备，并显示其模拟状态。 |
| 播放舞步 | 推进当前播放来源的模拟预览。 |
| 停止 | 停止当前预览并回到起始时刻。 |
| 清除全部模拟机 | 停止播放并释放当前模拟设备，同时卸载当前导入舞步。 |

> **联调提醒**：播放、暂停、跳转与停止可能改变地面站看到的模拟位置。需要观察真实指令结果时，先暂停自动预览。


## 02 组件安装、加载与更新

Scope 管理组件的安装、加载、工作区和移除。安装组件包后，还需要加载并打开对应工作区。

1. 在 Scope 的“文件”菜单选择“导入组件包…”，或进入插件管理使用“导入插件包”。
2. 选择完整的 Swarm 模拟组件包；支持交付的组件压缩包或 .sscomponent 组件文件。
3. 在组件卡片中核对名称“YSerein Swarm Simulator”。
4. 点击“加载插件”；已经加载时，点击“打开工作区”或“进入工作区”。
5. 确认中央出现模拟预览，左右和下方出现对应的会话、属性与诊断面板。

| 动作 | 含义 |
| --- | --- |
| 安装 / 导入 | 将组件加入本机组件库。 |
| 加载插件 | 使组件可用于当前 Scope 会话。 |
| 打开工作区 | 进入该组件的操作界面。 |
| 关闭工作区 | 关闭当前组件操作会话。 |
| 卸载组件 | 停止使用已加载的组件；按提示先关闭相关工作区。 |
| 移除插件 | 从本机组件库移除对应安装项。 |

### 更新已有组件

先结束当前模拟会话，再关闭相关工作区并按提示卸载组件。导入新组件包，按界面提示处理同名组件，然后重新加载。应保留完整的组件包和配套文件，避免只替换其中某个文件。

> **交付包区分**：YSerein Swarm 与独立模拟器的安装包，不会自动更新 Scope 内嵌模拟组件。Scope 组件更新请使用对应的组件包。


## 03 工作区与面板

中央查看运动与空间关系，左侧创建和控制会话，右侧查看模拟设备，下方查看诊断。

| 面板 | 主要内容 |
| --- | --- |
| 编队会话 | 导入舞步、选择播放来源、播放 / 暂停 / 停止、通信协议、网格生成、箱式设置与清除。 |
| 3D 模拟机编队 / 3D 舞步预览 | 显示当前来源的对象与运动；提供“重置视角”。 |
| 机群属性 | 模拟设备列表、选中设备的配置和状态编辑。 |
| 回放诊断 | 模拟对象数量、播放状态、命令接收与遥测目标。 |
| 底部播放栏 | 来源切换、播放、时间轴、时间显示和倍速。 |

### 显示与布局

- 左侧和右侧内容较长时滚动查看；可以拖动宿主面板分隔线调整空间。
- 面板被隐藏时，使用 Scope 的对应面板按钮或菜单恢复显示。
- 需要恢复面板布局时，使用“恢复当前页面默认布局”；中央组件布局可使用“恢复当前组件模板”。
- 窗口较窄时，底部的时间、倍速或对象数量可能收起。放宽窗口，或使用左侧会话中的播放控制。

> **数量的含义**：“模拟对象”表示组件当前创建的设备数量。地面站是否发现、是否在线、是否完成初始化，需要在地面站分别确认。


## 04 创建网格与通信协议

网格行列决定本次创建数量，间距决定初始布局。通信协议按照联调目标选择。

1. 在“网格编队”填写行、列和间距，检查界面显示的本次请求数量。
2. 查看当前对象与剩余容量；需要更换整个编队时，先清除已有模拟机。
3. 点击“一键生成”，等待对象数量更新，检查列表与 3D 画面。
4. 从少量对象开始使用，按本机资源和实际联调情况逐步增加数量。

| 协议选项 | 适用方式 |
| --- | --- |
| Private16（集群模拟） | 用于对应 YSerein Swarm 集群环境；创建数量以当前界面显示的上限和剩余容量为准。 |
| Standard8（1–250 台） | 用于相应标准 MAVLink 联调；单会话按界面限制创建 1–250 台。 |

通信协议选项标注“下次启动 Scope 生效”。更改选项后，安全结束模拟会话，关闭并重新启动 Scope，再确认当前会话使用所选协议。仅关闭一个面板不会完成协议切换。

> **重复生成**：生成操作会占用当前会话容量，不要将再次点击“一键生成”理解为替换原编队。需要新的独立场景时，先“清除全部模拟机”，等待归零后再创建。

软件允许创建的数量不等于当前电脑能够流畅运行的数量，也不等于地面站已经连接的数量。创建后持续关注应用响应、显示与通信状态。


## 05 箱式舞步

箱式舞步可以直接使用当前模拟机，无需先导入舞步文件。

1. 先生成模拟机，并选择“播放来源 → 箱式舞步”。
2. 在“箱式固定舞步”设置箱子行、列；默认可使用 3 × 4。
3. 确认界面显示已就绪，并查看箱位、层数和高度提示。
4. 点击“播放舞步”，观察每波起飞、全体前进、返回和逐层降落等阶段。
5. 需要调整箱位时，先暂停或停止，再修改行列并核对就绪提示。
6. 多层场景中可点击“预览整队起飞后”，快速查看后续水平运动阶段；再点击播放从该位置继续。

### 读懂就绪提示

模拟机数量需要满足界面提示的最小需求。数量不足时，可以增加模拟机，或减少箱子行列。大量设备使用较少箱位时，逐层起飞会持续较长时间；应结合当前波次和时间判断播放进度。

| 状态或操作 | 说明 |
| --- | --- |
| 起飞第 × / × 波 | 当前处于逐波起飞阶段。 |
| 全体前进 / 返回 | 当前处于水平运动阶段。 |
| 逐层降落 | 当前处于分层降落阶段。 |
| 预览整队起飞后 | 将时间轴跳到后续阶段并暂停，便于查看。 |

> **模拟场景**：箱式显示中的高度与运动仅用于模拟预览。时间跳转会改变模拟位置，不能代替一次完整的地面站作业流程。


## 06 导入舞步与播放控制

导入舞步用于查看对应文件的空间编排、灯光和时间进程。支持界面列出的 .yds 与 .zds 文件。

1. 需要一个干净的新场景时，先清除已有模拟机并等待归零。
2. 在左侧点击“导入舞步”，选择配套的 .yds 或 .zds 文件。
3. 选择“播放来源 → 导入舞步”，确认已就绪、对象数量和时间轴符合所选文件。
4. 点击“播放舞步”或底部播放按钮，查看时间递增以及对象运动和灯光变化。
5. 再次点击播放按钮暂停；左侧“停止”用于回到起始时刻。
6. 需要更换场景时，清除当前模拟机后重新导入，避免将不同场景的对象混在一起。

| 控制 | 用法 |
| --- | --- |
| 播放来源 | 在箱式舞步与导入舞步之间切换；切换会暂停正在播放的来源，之后按所选来源重新播放。 |
| 时间轴 | 先播放再暂停，然后拖动到需要查看的时刻；查看后点击播放继续。 |
| 停止 | 停止当前来源的播放并返回起点；不会清除模拟机或原始文件。 |
| 倍速 | 底部支持 1×、2×、3×、5×、10×；用于调整预览速度。 |
| 时间显示 | 显示当前时间与总时长；窗口较窄时可收起。 |

> **两端文件**：与地面站共同使用时，应确认双方文件属于同一场舞步。Scope 能打开 .zds，不代表地面站的 .yds 入口能通过改名打开同一文件。


## 07 3D 视角与设备属性

使用 3D 场景查看编队和舞步；在机群属性中选择设备并编辑其模拟状态。

| 3D 操作 | 方法 |
| --- | --- |
| 缩放 | 在 3D 画面上使用鼠标滚轮靠近或远离。 |
| 移动 | 先点击 3D 画面获得焦点，再使用 W、A、S、D 移动视角。 |
| 转动 | 在画面中按住鼠标并拖动，调整观察方向。 |
| 重置 | 点击画面上方“重置视角”，重新适配当前场景。 |

### 查看与调整模拟设备

1. 在右侧模拟设备列表选择目标设备，检查详情中的模拟设备编号。
2. 修改电量或航向后，点击对应“应用”。
3. 需要移动对象时，填写局部坐标并点击“应用坐标”。
4. 查看画面、列表与地面站反馈是否符合本次调整。

设备属性调整作用于模拟对象，不修改原始舞步文件。播放中的轨迹位置可能重新覆盖手动坐标；需要保持手动场景时，先暂停播放。

> **模拟数值**：列表中的电量、位置与设备状态属于模拟数据，不应当作真实电池、真实定位或实际飞行状态。


## 08 与 YSerein Swarm 联调

Scope 创建模拟设备并提供遥测，地面站负责设备发现、初始化与对应操作。分别观察两端状态。

| 连接项 | 地址或端口 |
| --- | --- |
| 模拟组件遥测目标 | 192.168.20.251:37890 |
| 模拟组件命令接收 | 0.0.0.0:37880；表示监听本机可用网卡，不是需要填入的远端目标地址。 |
| 地面站配置 | 在“设置 → 通用”启用模拟设备模式，按提示重启；连接地址与现场广播配置应匹配。 |

1. 确认当前网络只包含允许受控的模拟设备，并核对两端通信设置。
2. 在 Scope 创建少量模拟机，查看“回放诊断”的对象数量与地址。
3. 在地面站观察对应设备出现、位置更新和初始化进度。
4. 先暂停 Scope 自动预览，再在地面站核对单机或批量目标，执行所需操作。
5. 同时查看地面站的消息、模式与设备反馈，确认影响范围符合预期。
6. 需要演示舞步时，再选择适合的播放来源并播放；预览播放与地面站表演流程分别使用。

> **操作结果**：Scope 的 3D 预览与手动属性可能影响模拟位置；不能仅凭画面运动判断某条地面站命令已执行。地面站顶部全体应急广播还可能覆盖列表外的其他接收设备。

停止 Scope 播放不会向真实飞机发送降落命令；关闭 Scope 也不能代替地面站对设备的安全处置。真实设备作业与模拟联调应使用各自明确的操作环境。


## 09 清除、重建与关闭

清除用于结束当前模拟场景。待组件给出完成提示并且数量归零，再开始下一场景。

1. 在左侧“网格编队”点击“清除全部模拟机”。
2. 阅读确认提示；点击“取消”保留当前场景，点击“确认清除”结束当前场景。
3. 等待“正在清除…”结束，确认出现可重新生成或导入的提示，对象数量归零。
4. 需要继续使用时，重新生成网格或导入舞步，并核对新对象数量。
5. 结束使用时，完成必要的地面站收尾，再关闭 Scope 当前工作区；需要更新组件时，随后按提示卸载。

| 清除后的内容 | 结果 |
| --- | --- |
| 当前模拟机 | 清除。 |
| 当前播放与导入舞步 | 停止并卸载。 |
| 原始舞步文件 | 保留。 |
| 地面站设备列表 | 由地面站按通信状态处理，可能继续保留离线记录。 |

> **两端收尾**：地面站中保留的离线设备，应在确认不再需要后按地面站流程移除。清除 Scope 模拟机不会停止地面站正在进行的应急重发，需要分别处理。


## 10 常见问题

先确认当前播放来源、对象数量和会话状态，再处理对应问题。

| 现象 | 处理方法 |
| --- | --- |
| 组件库中没有模拟组件 | 导入完整的对应组件包，再核对组件名称并加载。 |
| 组件导入或加载失败 | 查看 Scope 提示，核对组件包完整性与宿主兼容性；更新正在使用的组件前先关闭工作区。 |
| 缺少清除或播放入口 | 核对已加载组件版本；Scope 组件需要使用对应组件包更新。 |
| 一键生成不可用 | 检查请求数量与剩余容量，并确认当前不在清除过程中；需要新场景时先清除。 |
| 箱式舞步不能播放 | 按就绪提示增加模拟机或减少箱子行列，并确认播放来源为箱式舞步。 |
| 导入后不能播放 | 检查来源、文件类型与加载提示，确认对象和时间轴出现；文件不匹配时重新选择配套文件。 |
| 播放了却像没有移动 | 观察当前波次与时间。多层起飞需要时间，可使用“预览整队起飞后”查看后续阶段。 |
| 3D 空白或找不到机群 | 检查对象数量与来源，点击“重置视角”，再调整滚轮；查看组件加载提示。 |
| 键盘移动不起作用 | 先点击 3D 画面获得焦点，避免焦点停留在输入框。 |
| 协议选择后没变化 | 关闭并重新启动 Scope，再核对当前会话协议提示。 |
| Scope 有对象，地面站没有设备 | 检查地面站模拟设备模式、本地地址、端口、广播配置及防火墙；分别观察发现与初始化。 |
| 清除后地面站仍有设备 | 设备可能作为离线记录保留；确认安全后在地面站按需移除。 |

> **规模增加**：增加模拟规模时持续观察应用响应、画面和通信。发生卡顿或通信异常时先减少对象并定位当前环节，不以模拟对象数量代替连接成功数量。
