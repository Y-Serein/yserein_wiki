# 常见问题

## 组件导入后打不开？

先检查组件包的 ID、版本、ABI 和目标平台，再确认 Qt、编译器、CPU 架构与 Core SDK 是否匹配。组件可能已导入但尚未加载，也可能因旧工作区未关闭而无法切换同 ID 版本。查看组件管理中的具体错误，不要直接覆盖运行中的 DLL。

## 串口显示被占用？

同一端口在 Scope 内由 Core 租约独占。先断开另一工作区，再确认外部串口工具是否占用该端口。设备拔插后重新扫描端口；不要在两个组件中并行打开同一设备。

## 数值波形没有数据？

检查端口、波特率和解析引擎。Delimited numeric 需要设备按行发送可解析的数值字段；先用 Raw text 确认真实输入，再切换解析。终端发出的换行方式也需符合设备协议。

## USB NCM 设备连接不上？

确认设备实际处于对应 USB NCM 模式、固件与网络接口已就绪，并检查组件显示的设备地址。TN160/T256/T384/T640 的协议与工作流不同，不能仅凭同一个网络地址互换组件。连接失败时先看组件的诊断与身份信息。

## 热图有画面却没有摄氏度？

RAW16/Y16 画面本身不代表已有可用温度模型。T256/T384/T640 组件只有在读取到有效模型时才显示温度；实验性两点模型也不等于 OEM 正式测温。先检查模型状态和设备回读，不要为了显示数值而跳过校验。

## 标定命令响应不确定怎么办？

停止后续写入，保持设备状态，重新连接并只读核对组件报告的事务和回读结果。不要盲目重发保存或擦写命令。真实设备的异常恢复应依对应固件与现场流程处理。

## HMI 预览成功，为什么屏幕没有更新？

当前 HMI 组件提供离线设计、预览和本机目标包。真实串口通信与硬件下载需要目标后端及设备支持；预览成功只证明本机工程路径。

## 可以安装任意第三方组件吗？

原生组件在宿主进程内运行，具备同等系统权限。仅安装可信来源并确认 SDK 与目标宿主兼容。当前没有把原生插件作为安全沙箱，也不保证任意旧版组件跨 Core 版本直接运行。

## 配置和组件存在哪里？

便携部署默认在程序旁的 `runtime/` 保存运行时数据，在 `Components/` 保存组件。安装目录需要相应写入权限。组件仓库可用 `SEREIN_COMPONENT_DIR` 覆盖；具体导出文件路径以组件界面显示为准。
