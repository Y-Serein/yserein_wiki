# 思维导图与 XMind

思维导图使用当前 Markdown 的结构，源码、富编辑与导图之间保持同一文档。使用适配查看全图，使用 100% 恢复实际字号；需要保留细节时展开对应分支。

## 编辑结构

使用节点操作与快捷键调整标题、增加分支、折叠或移动主题。完成中文输入后再执行结构操作；遇到不符合预期的变化，先撤销并检查源码，再继续保存。

## 导入 XMind

导入时选择一个或多个工作表，新建独立草稿，原工作簿不被改写。支持的图片与部分关系、概要、样式元数据随文档保留。源码中用于往返的专用 HTML 注释不要随意删除。

XMind 的任意拓扑、外部资源和全部视觉布局不保证完整还原。重要工作簿保留原件，导入后逐项检查，不能用“导入成功”代替内容一致性核对。

## 导出副本

可导出 SVG、PNG、PDF 与 XMind。根据入口选择全图、当前展开或选中分支范围；PNG 支持倍率与透明背景。导图 PDF 使用高分辨率图像，不是可选择文字的矢量 PDF。

选择保存位置后，在目标应用打开副本，核对文字、图片、关系线及工作表。取消或失败时保留当前草稿；只有实际生成文件后才按导出完成处理。
