# 用户手册

## 文件与 Vault

需要补齐：

- 创建、打开、重命名、移动和删除文件。
- 目录懒加载和大目录行为。
- 外部工具修改文件后的刷新规则。
- 文件冲突、只读文件和编码处理。

## Plain Edit

说明 CodeMirror 编辑行为、Markdown 语法、查找替换、撤销重做、组合输入和快捷键。

## Rich Edit

说明 Milkdown 富文本编辑、块级操作、光标行为、粘贴、图片、表格和与原始 Markdown 的一致性边界。

## 大纲、反链和图谱

分别说明：

- 数据来源和刷新时机。
- 链接语法和路径解析。
- 大目录下的性能限制。
- 不存在、重命名和循环链接的表现。

## 标签

说明标签语法、索引、搜索和重命名规则。

## 外观和设置

需要记录：

- 主题、字号、字体和布局。
- 中英文界面。
- 快捷键配置。
- 设置存储位置和恢复默认。

## 文件关联

正式文档应说明 Markdown/Text 文件关联的支持系统、安装权限、取消关联和故障处理。

## 常见问题

- 中文输入法候选框或组合输入异常。
- Rich/Plain 切换后格式变化。
- 文件树未刷新。
- 大文档卡顿。
- WebView2 缺失或版本异常。
- 文件关联未生效。
