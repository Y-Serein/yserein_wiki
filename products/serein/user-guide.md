# 用户手册

## 文件与 Vault

Vault 是用户选择的本地文件夹，Markdown 与文本保留为普通文件。文件树按需读取目录；打开独立文档不必创建 Vault。创建、重命名或删除前核对目标路径。重要目录先备份，删除后的恢复依赖实际文件备份。

在应用外修改文档时，先确认当前编辑是否已保存，再刷新或重新打开文件。多款编辑器或同步工具同时写同一个文件可能造成冲突；不要用覆盖保存代替核对差异。

## 源码编辑与富编辑

源码视图使用 CodeMirror，适合直接检查 Markdown、查找替换和调整语法。富编辑视图提供表格、公式、图片等内容的阅读和编辑。两者基于同一个 Markdown buffer，切换视图不是转换成另一份文档。

使用撤销、重做和组合输入时，先完成当前中文输入。处理复杂格式后，可回到源码视图检查原始内容，再保存。快捷键和显示方式在应用设置与菜单中查看。

## 表格、公式与导出

表格使用标准 Markdown 结构，可调整行、列与对齐。数学公式使用 LaTeX 定界符；复杂公式和 DOCX 导出方法见[数学与导出](math-export)。

导出生成独立副本。保留原 Markdown 与资源文件，便于继续编辑和恢复；不同输出格式的能力分别说明，不把 DOCX、HTML 与 PDF 视为相同排版结果。

## 大纲、反链与图谱

大纲按文档标题组织。反链与本地图谱用于查看文档引用关系；移动或重命名文件后检查关联链接。找不到目标的链接需要修正路径，不应把缺失文件当成空内容覆盖保存。

## 思维导图与 XMind

导图显示 Markdown 的结构，也提供 XMind 导入和导出副本。有关多工作表、图片、元数据和格式边界，阅读[导图手册](mindmap)。

## 设置与常见问题

界面支持中文与英文；字体、字号、主题、布局和快捷键可在设置中调整。问题反馈请附应用版本、操作系统与最小复现。导出或打开失败时保留原文件，不在未确认原因时反复覆盖。
