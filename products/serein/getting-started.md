# 快速开始

## 安装与启动

Serein 当前安装器面向 Windows x64。先在[下载中心](/downloads/#serein)核对版本、来源和文件校验，再运行安装器。启动需要 Microsoft Edge WebView2 运行环境；启动失败时先检查运行环境和系统提示。

## 打开本地文件

1. 选择“打开本地文件夹为 Vault”，使用一个用于写作的文件夹。第一次尝试可选文件夹副本。
2. 在文件树中打开 Markdown 文件，或使用“打开独立 Markdown”编辑单个文档。
3. 在源码编辑与富编辑之间切换。两种视图操作同一份 Markdown 内容。
4. 保存文档，并在原文件夹确认保存位置。尚未保存的草稿需要选择实际文件路径。
