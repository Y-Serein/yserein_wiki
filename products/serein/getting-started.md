# 快速开始

最终目标：让新用户在几分钟内完成安装、选择本地目录、创建文档、切换编辑模式并确认文件可以被其他工具打开。

::: warning 发布状态
Windows 正式安装包、下载地址和完整兼容性尚待维护者提供。当前页面先建立用户流程框架。
:::

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 版本范围待补 |
| WebView2 | 安装方式和最低版本待补 |
| 磁盘空间 | 待补 |
| 支持文件 | Markdown、Text；扩展名范围待补 |

## 2. 下载与安装

从[下载中心](/downloads/)获取正式安装包，并核对版本和 SHA-256。不要从不明来源下载重新打包的安装程序。

## 3. 创建或打开 Vault

Vault 是 Serein 管理的本地文件夹。正式文档应说明：

- 创建新目录。
- 打开已有 Markdown 文件夹。
- 目录权限和网络盘限制。
- Serein 是否创建隐藏配置文件。

## 4. 创建第一篇文档

1. 在文件树中新建 Markdown 文件。
2. 使用 Plain Edit 输入原始 Markdown。
3. 切换 Rich Edit 检查渲染效果。
4. 保存并用系统文件管理器确认原始文件存在。

## 5. 备份

在导入重要资料前先阅读[数据与隐私](/products/serein/data-privacy)，确认备份、迁移和异常恢复方式。
