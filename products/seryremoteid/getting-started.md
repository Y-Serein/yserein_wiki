# 快速开始

首次接入按以下步骤让第一次接触产品的用户，在不阅读源码的情况下完成：

```text
确认型号 → 正确接线 → 安全供电 → 配置身份 → 接入飞控 → 确认广播
```

::: warning 型号与接入条件
产品硬件参数、正式接线图、供电范围、默认配置和广播确认方式需按实际型号确认。补齐前请勿依据本页占位内容直接接线或上电。
:::

## 1. 开箱检查

接入时请检查：

- 产品型号与硬件版本识别位置。
- 主机、线材、天线和配件清单。
- 外观损伤、接口和防呆检查。
- 对静电、天线和供电的安全提醒。

<p>具体型号资料请通过<a href="/support/">支持渠道</a>确认。</p>

## 2. 确认飞控平台

当前维护者报告的目标生态包括：

- APM
- PX4
- 凌动 5（正式品牌、型号和版本名待确认）

具体连接方式和兼容版本在[飞控集成](/products/seryremoteid/integrations)中维护。

## 3. 接线与供电

接线前必须确认：

1. 产品硬件版本。
2. 供电电压和峰值电流。
3. UART 或 CAN 接口电平。
4. TX/RX 或 CAN-H/CAN-L 线序。
5. 是否需要共地和终端电阻。
6. 天线是否必须在上电前连接。

<p>具体型号资料请通过<a href="/support/">支持渠道</a>确认。</p>

## 4. 第一次启动

首次启动时请确认：

- 上电后的正常 LED 顺序。
- 默认工作模式。
- 如何访问 Web 状态页。
- 如何判断设备已读取飞控数据。
- 如何判断 WiFi/BLE 正在广播。

## 5. 配置身份信息

Remote ID 身份字段、Operator ID、UAS ID、BasicID 和地区要求需要根据目标场景配置。完整字段见[参数配置](/products/seryremoteid/configuration)。

::: danger 不要使用示例身份投入实际运行
示例或默认身份只能用于实验。实际使用必须由设备所有者或集成方按当地法规填写并承担合规责任。
:::

## 6. 验证成功

最终的成功判据至少包括：

- 状态页显示正确的飞控来源和身份状态。
- 输入数据持续更新，没有超时或错误状态。
- WiFi/BLE 抓包或合规接收工具能收到预期广播。
- 重启后必要参数仍然保持。
