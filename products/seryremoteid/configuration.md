# 参数配置

配置文档必须同时说明“参数含义、允许范围、默认值、生效方式、持久化位置和错误风险”。只列参数名不构成用户手册。

## 配置入口

仓库表明固件包含 NVS 参数、MAVLink/DroneCAN 参数服务、SecureCommand 和 Web 状态接口。产品版本实际开放哪些入口、是否需要权限、修改后何时生效，待维护者确认。

| 配置方式 | 适用场景 | 权限/安全 | 当前文档状态 |
|---|---|---|---|
| Web 页面 | 现场查看与配置 | 按型号确认 | 状态接口已存在，操作流程按型号确认 |
| MAVLink 参数 | APM/PX4 集成 | 按型号确认 | 参数服务存在，兼容版本按型号确认 |
| DroneCAN 参数 | CAN 集成 | 按型号确认 | 参数服务存在，兼容版本按型号确认 |
| SecureCommand | 受控管理 | 公钥与命令验证 | 用户流程按型号确认 |

## 身份参数

应逐项补齐：

- UAS ID / BasicID 类型与格式。
- Operator ID。
- 飞行器类型与分类。
- 位置信息来源。
- Emergency、System、Self ID 等消息的来源和更新规则。
- 空字段、无效字段和重复身份的处理方式。

::: danger 身份数据责任
公开文档可以解释格式和流程，但不能提供可直接用于真实运行的伪造身份。实际身份内容由设备所有者、厂商或运营者按法规配置。
:::

## 输入参数

| 参数类别 | 需要说明 |
|---|---|
| MAVLink UART | 端口、波特率、协议版本、消息频率、超时 |
| DroneCAN | 节点 ID、动态分配、bitrate、服务、超时 |
| 输入优先级 | 多输入同时存在时如何选择 |
| 状态新鲜度 | 何时判定数据过期、如何恢复 |

## 广播参数

仓库当前包含 WiFi Beacon/NAN、BLE 4 legacy 和 BLE 5 coded extended advertising。产品文档还需说明：

- 每种广播模式的启用条件。
- 广播周期及允许范围。
- WiFi 信道和地区限制。
- BLE 4/5 的兼容设备范围。
- 多种广播并发的资源与时序影响。

## 安全与系统参数

仓库中存在 `LOCK_LEVEL`、`PUBLIC_KEY1..5`、`CAN_NODE`、`UAS_ID`、`BT4_RATE`、`BT5_RATE` 等参数。正式参数表应包含：

| 参数 | 类型 | 默认值 | 范围 | 重启要求 | 错误风险 |
|---|---|---|---|---|---|
| `LOCK_LEVEL` | 按型号确认 | 按型号确认 | 按型号确认 | 按型号确认 | 可能影响配置与升级权限 |
| `CAN_NODE` | 按型号确认 | 按型号确认 | 按型号确认 | 按型号确认 | 节点冲突 |
| `UAS_ID` | 按型号确认 | 按型号确认 | 按型号确认 | 按型号确认 | 身份无效或不合规 |
| `BT4_RATE` | 按型号确认 | 按型号确认 | 按型号确认 | 按型号确认 | 广播频率与资源占用 |
| `BT5_RATE` | 按型号确认 | 按型号确认 | 按型号确认 | 按型号确认 | 广播频率与资源占用 |

## 备份与恢复

需要确定是否支持配置导出、恢复出厂、迁移到新硬件，以及恢复操作对身份、密钥和 secure version 的影响。
