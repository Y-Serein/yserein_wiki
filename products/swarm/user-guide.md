# YSerein Swarm · 地面站用户使用手册

用于设备接入、状态查看、单机与批量操作，以及无人机编队表演的准备和执行。

文档版本：1.0 · 2026 年 10 月

- 适用对象：现场操作人员、设备管理员与编队作业人员。
- 阅读建议：首次使用先读快速上手；执行表演前阅读表演流程与应急处理。
- 真实设备操作必须符合现场安全条件。界面提示、设备回报与实际飞行状态需要分别确认。

## 01 快速上手

先建立连接并查看设备，再按需要进入设备操作或表演流程。普通设备查看与控制不要求先载入舞步。

1. 通过安装器安装 YSerein Swarm，完成后启动应用。
2. 选择登录方式，进入工作区；核对账号与授权提示。
3. 打开顶部齿轮“设置”，在“连接”中核对现场网络配置。
4. 打开“无人机”页面，查看设备列表、在线状态和初始化进度。
5. 点击设备行查看详情。需要单机操作时，取消“批量操作”；需要批量操作时，先勾选目标设备。
6. 先核对目标文字和数量，再确认操作。执行结果结合设备状态与消息查看。

### 两种日常工作方式

| 工作方式 | 主要入口 | 重点 |
| --- | --- | --- |
| 设备管理 | 无人机 → 设备操作 / 设备详情 | 检查连接、选择目标、查看状态并按需操作。 |
| 编队表演 | 无人机 → 表演流程；表演页面 | 载入舞步、确定场地与编号、上传、授权起飞、执行。 |

> **先认清目标**：查看某台设备的详情，不会自动将批量操作改成单机操作。始终以“当前设备”或“已选 × 台设备”的提示为准。


## 02 登录与账户

登录后使用账户对应的作业权限。账号登录与现场飞机连接是两件事，需要分别确认。

| 入口 | 操作方法 |
| --- | --- |
| 一键登录 | 本机已有登录记录时显示。点击后按页面提示继续使用本机账号。 |
| 浏览器登录 | 点击后在系统浏览器完成登录，再返回应用。账户服务：https://cloud.yserein.com。 |
| 账号邮箱登录 | 展开邮箱入口，填写邮箱，点击“发送验证码”，完成页面安全验证，输入邮件中的 6 位验证码，点击“验证并登录”。 |

### 登录遇到问题

- 邮箱验证码未收到时，先检查邮箱地址与垃圾邮件，再使用“重新获取”。
- 安全验证或邮箱登录失败时，按提示重试，或改用“浏览器登录”。
- 登录等待较长时，可使用“取消”结束当前请求，再选择适合的登录方式。
- 账户服务连接失败时，核对网络与系统时间，并查看页面给出的具体原因。

### 每日授权与退出账号

应用启动时联网刷新授权；每天北京时间 05:00 后需要重新联网校验。当日校验成功后可按授权范围离线工作。界面提示授权刷新或权限不足时，先完成联网校验，再开始新的受控作业。

账户入口位于顶部齿轮“设置 → 账户管理”。退出登录会清除本机登录凭据与授权；在设备仍需现场处置时，先完成安全收尾。飞行中的降落、返航与必要安全处置保持本地可用，仍需具备现场通信链路。


## 03 工作区与状态阅读

工作区围绕设备、现场视图和操作流程组织。通过状态和数量确认进度，不只看按钮颜色。

| 区域 | 用途 |
| --- | --- |
| 顶部栏 | 连接概况、消息中心、应急处理与设置入口。 |
| 无人机列表 | 查看设备、勾选目标，按需切换列表或网格显示。 |
| 现场视图 | 查看设备位置，切换二维 / 三维视图，使用测距与框选。 |
| 右侧操作区 | 表演流程、辅助操作、设备操作与列表工具。内容较长时可滚动查看。 |
| 设备详情区 | 查看所选设备的状态、参数、消息与其他设备功能。 |

### 应当分别确认的状态

| 状态 | 说明 |
| --- | --- |
| 在线 | 地面站正在接收该设备的有效通信。 |
| 初始化 | 设备信息与相关数据的获取进度；与在线状态分别查看。 |
| 已选 | 本次普通批量操作的目标范围。 |
| 已匹配 / 本次参与 | 设备与舞步编号的对应关系，以及本次表演实际参与数量。 |
| 已上传 | 参与设备的舞步传输完成情况。 |
| 授权起飞 / 飞行模式 | 现场准备状态与设备上报模式；不能直接代替实际起飞或落地确认。 |

> **离线数据**：设备失联后，最后显示的位置或数值只能作为参考。先核对通信状态，再判断数据是否仍能用于当前操作。


## 04 网络连接与模拟设备模式

在“设置 → 连接”中核对本地地址、端口、广播地址与连接超时。按现场已确定的网络方案填写。

| 项目 | 使用说明 |
| --- | --- |
| 地面站本地地址 | 默认使用 192.168.20.251；运行地面站的网卡需要具备该地址。 |
| 地面站接收端口 | 默认使用 37890；模拟组件向 192.168.20.251:37890 发送遥测。 |
| 广播地址 | 使用现场网络方案指定的广播地址，确保广播范围覆盖预期设备。 |
| 连接超时 | 单位为毫秒；默认 10000 毫秒，即 10 秒。 |
| 配置生效 | 带重启提示的配置项，在安全结束当前会话后重启应用生效。 |

### 与 Scope 模拟组件连接

1. 确认当前联调网络中只包含允许受控的模拟设备。
2. 在“设置 → 通用”启用“模拟设备模式”，按界面重启提示生效。
3. 在 Scope 中加载 Swarm 模拟组件并生成少量设备。
4. 确认地面站接收地址为 192.168.20.251:37890，模拟组件命令接收端口为 37880。
5. 在地面站观察设备发现与初始化，并核对设备数量；只出现在线设备不能代替初始化进度确认。

> **现场与模拟分开**：切换到真实设备作业前，关闭模拟设备模式并按提示重启。避免在同一广播范围内混入真实设备和模拟设备。


## 05 单机与批量设备操作

设备操作区默认使用“批量操作”。确认框会显示此次操作的目标和内容。

1. 单机操作：点击设备查看详情，取消“批量操作”，确认目标为当前设备。
2. 批量操作：保留“批量操作”，勾选需要操作的设备，检查已选数量。
3. 点击所需操作，阅读确认框中的设备范围、动作与失联提示。
4. 确认后查看消息和设备反馈；如果结果不明确，先核对当前状态，再决定后续操作。

| 操作 | 使用要点 |
| --- | --- |
| 解锁 / 上锁 | 仅在满足现场条件时使用。空中上锁会停桨，不能作为普通降落方式。 |
| 起飞 | 该入口请求起飞至 1 m，实际高度不低于飞控设置；用于对应设备控制流程。 |
| 飞行模式 | 从列表选择模式并确认；以设备随后上报的模式为准，需匹配实际机型与固件。 |
| 灯光 | 选择颜色、效果和持续时间，核对目标后应用。 |
| 降落 / 返航 | 仅作用于确认的目标设备；持续观察设备反馈和实际状态。 |
| 初始化 | 重新获取设备信息；失联设备需要恢复通信后才能推进。 |
| 重启 | 仅在设备已安全停止时使用，重启期间通信会中断。 |
| 删除 | 从地面站移除设备记录；不等于停止飞机或取消机上任务，仍在通信的设备可能再次出现。 |

> **失联目标**：失联设备可能仍保留在操作范围内。界面会给出相应提示；尝试发送不能等同于飞机已收到或执行。


## 06 应急处理与停止重发

顶部“应急处理”用于全体广播处置。广播范围与设备操作区的勾选范围不同。

1. 点击顶部“应急处理”，展开可选动作；展开菜单本身不发送命令。
2. 按现场情况选择“全部悬停 · LOITER”“全部降落 · LAND”或“全部返航 · RTL”。
3. 选择后立即开始广播，每 3 秒重发，最长持续 10 分钟。
4. 观察按钮和消息中的已知设备确认数量，同时确认实际设备状态。
5. 需要停止后续重发时，再次点击顶部按钮，或在应急面板点击“停止重发”。到达 10 分钟期限后也会停止重发。

> **广播范围**：全体广播会影响广播范围内能够收到命令的飞机，包括地面站未登记或已移除的飞机。即使列表为空，仍可能有设备接收广播。

界面确认数量只统计地面站已知设备。全部已知设备确认后仍会继续重发，直至操作者停止或达到期限。确认了某种模式，不等于已经落地。

### 重发期间执行定向操作

| 冲突弹窗选择 | 结果 |
| --- | --- |
| 取消 / Cancel | 全体重发继续；本次定向操作不发送。 |
| 是 / Yes | 同意停止全体重发并执行本次定向操作；以消息提示核对结果。目标变化或链路不可用时，可能保留重发并拒绝本次操作，应按提示重新选择或恢复连接。 |

> **取消的含义**：停止重发只停止未来的重复发送。已经发出的命令不会撤回，设备也不会因此自动恢复之前的状态。显示“应急链路不可用”时，先检查现场连接设置与网络。


## 07 表演准备：载入、场地与编号

表演流程使用对应舞步文件与现场设备。普通设备操作和表演准备分别进行。

1. 在“无人机 → 表演流程”点击“载入舞步”，选择配套的 .yds 文件。不要通过修改扩展名转换文件。
2. 打开“表演 → 表演信息”，核对舞步名称、无人机数量和相关检查结果。
3. 在“表演 → 表演设置”核对舞步航向角，填写后点击“保存”。
4. 按现场布置确定参考桩位置。在设备地图菜单中可使用“当前位置设为桩 1”“当前位置设为桩 2”；选择的设备与位置必须符合本场舞步要求。
5. 回到表演流程，点击“自动编号”。需要手动调整时，使用设备菜单中的“匹配舞步编号”。
6. 核对设备与舞步编号的对应关系，以及“计划 / 已匹配 / 本次参与”的数量。

### 准备过程中需要关注

- “表演信息”提供起降点、速度加速度、间距和高度等检查入口；按作业要求查看检查结果。
- 地图中的参考桩、航向和匹配连线应与实际场地一致，不能只凭编号完成提示判断位置正确。
- 如果某一步不可操作，阅读该步骤给出的原因，处理对应条件后再继续。
- 已匹配数量、本次参与数量和计划数量可能不同，需要按本次作业方案逐项核对。

> **切换舞步**：需要更换文件时，先安全结束当前作业，再使用“清除舞步”清除当前准备状态后重新载入。清除地面站舞步不能代替设备的安全处置。


## 08 表演执行：上传、授权与起飞

按右侧表演流程依次操作。每一步确认当前结果与参与设备，再进入下一步。

1. 点击“上传至飞机”，在上传窗口确认参与设备范围，再点击“上传舞步”开始传输。
2. 查看总进度、用时及等待中、上传中、已完成、失败列表。核对本次参与设备的完成情况；失败项按提示处理后再继续。
3. 传输需要中止时，使用上传窗口中的“取消”。取消不能代替核对设备已收到的文件。
4. 准备条件满足后，点击“授权起飞”，检查对应的现场准备状态。
5. 需要进行悬停检查时，在“辅助操作”使用“悬停测试”，按窗口提示和现场流程进行。
6. 起飞区域、设备、通信和现场人员均已满足作业条件后，点击“10 秒后执行”。持续观察倒计时、设备模式、位置和飞行状态。
7. 表演结束后逐机确认落地与安全状态，再清除舞步或退出应用。

> **两种授权**：账户作业授权决定本机可用的作业权限；“授权起飞”是本次表演的现场准备步骤。登录成功不等于已经授权起飞，授权起飞也不等于设备已经升空。

上传仍在进行时点击授权起飞，界面可能询问是否取消传输并继续。应先确认全部计划参与设备的传输结果，再决定是否继续。

“取消授权”用于撤销相应准备状态。飞行中需要降落、返航或悬停时，使用对应现场安全控制并确认设备反馈。


## 09 设备查看与维护

点击设备查看详情；顶部齿轮用于应用配置，导航“设置”页面用于相应设备维护功能。

| 入口 | 用途与操作要点 |
| --- | --- |
| 详细信息 | 查看电池、定位、机体与动力等信息；缺少数值时先核对连接和设备回报。 |
| 无人机消息 / 系统状态 | 查看设备提示与状态，处理具体故障原因。 |
| 参数设置 | 选择设备和参数，记录原值再修改；保存后核对设备回报与实际值。 |
| 传感器校准 | 按设备对应的校准提示执行；确保设备停机、位置合适并完成现场准备。 |
| Mavlink / 文件系统 | 查看对应消息或设备文件；文件读写会影响目标设备，先核对目标。 |
| 设置 → 无人机设置 | 访问对应设备维护与固件更新入口；选择与设备匹配的文件，并确保供电与连接可靠。 |
| 顶部设置 → RTK | 按现场差分定位方案配置连接；以每台设备实际定位状态为准。 |

### 维护前后

- 参数写入、校准、重启与固件更新在设备安全停机后进行。
- 批量参数操作先核对实际作用范围；不要把正在查看的单机误认为批量目标。
- 修改后核对每台目标的响应。部分成功时，只处理失败或结果不明确的目标。
- 保存必要的原参数与维护记录，便于恢复和后续排查。

> **数值含义**：按界面标注的单位输入。不同机型或固件的参数与模式可能不同，应以当前设备适用的说明和实际回报为准。


## 10 常见问题与安全收尾

根据当前现象处理对应环节。需要再次执行设备动作前，先确认上一条动作的结果。

| 现象 | 处理方法 |
| --- | --- |
| 列表没有设备 | 核对设备或模拟组件是否运行、本地地址和端口、网络连通性及防火墙；不要只检查账号登录。 |
| 设备在线，但初始化等待 | 查看设备初始化进度与消息；确认通信能双向工作。必要时对目标重新初始化。 |
| 查看了某机，却提示没有目标 | 检查“批量操作”和勾选数量；单机控制需取消批量操作。 |
| 操作超时或设备无响应 | 检查链路及设备状态，区分未发送与结果不明确；避免重复点击起飞或解锁。 |
| 授权刷新或权限不足 | 检查账户、网络、时间及权益提示；完成校验后再开始新的受控作业。 |
| 上传存在失败设备 | 在上传窗口查看失败项，恢复对应连接并核对传输结果，不以总进度替代逐机确认。 |
| 应急链路不可用 | 检查默认连接及广播网络配置；持续核对设备状态，按现场应急流程处理。 |
| 地图空白或视角偏离 | 核对当前视图、地图连接与设备位置；尝试调整二维 / 三维视图和缩放。 |

### 结束一次作业

1. 确认全部参与设备实际落地并处于安全状态。
2. 若应急重发仍在进行，按现场需要停止后续重发。
3. 确认传输与维护动作已经结束，再清除当前舞步或设备记录。
4. 按需退出账号并关闭应用，保存本次作业的必要记录。

> **反馈不等于物理结果**：“已发送”“模式已确认”“已上传”分别描述不同进度。安全收尾以设备实际状态与现场确认共同判断。
