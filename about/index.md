# 关于 Y-Serein

Y-Serein 是由一位核心维护者主导的独立工程与开源项目品牌，当前专注无人机硬件、嵌入式固件、桌面软件，以及可信智能计算与智能物理系统相关工程。

不公开真实姓名不影响产品专业性。用户可以通过产品、文档、版本、维护记录、GitHub 提交和验证证据判断项目质量。

## 核心维护者

**Y-Serein — Core Maintainer / System Architect**

当前主要负责：

- 产品方向和系统架构。
- 硬件、固件与桌面软件开发。
- 飞控集成与工程验证。
- 用户文档、版本发布和支持流程。

后续贡献者按 GitHub 账号和实际贡献记录公开，不虚构团队规模或组织职位。

## 产品原则

- 产品必须有明确用户和使用任务。
- 硬件、固件、软件和文档属于同一交付物。
- 兼容性、已知问题和未验证边界公开说明。
- 编译通过不代替上板、抓包、总线、性能或法规验证。
- 安全、可靠、实时由证据支持，不作为装饰性标签。
- 用户隐私、设备身份、密钥和签名材料不进入公开文档。

## 开源与商业边界

不同项目使用各自许可证。开源代码、硬件销售、集成支持和合规责任需要分别说明，不能互相替代。
