# 路线图

路线图优先完善现有产品交付，不以新增仓库数量作为进度。

## 第一阶段：产品门户与文档框架

- 建立 Y-Serein 产品官网、文档、下载、支持和团队入口。
- 完成 SeryRemoteID 用户手册、开发者文档和版本框架。
- 完成 Serein 安装、使用、数据与发布框架。
- 区分产品、研究工作区和历史草稿。

## 第二阶段：补齐真实材料

### SeryRemoteID

- 补充产品实物图、型号、硬件版本和接线图。
- 补充 APM、PX4、凌动 5 的准确型号、版本和验证范围。
- 发布固件、校验值、升级/回滚说明和兼容矩阵。
- 补充用户手册、常见故障、Web 页面和演示材料。
- 补充 WiFi/BLE 抓包、DroneCAN、OTA、稳定性和时延验证。

### Serein

- 补充正式截图、安装包、版本和下载校验值。
- 完成 Windows、IME、WebView2、文件关联和大文档验证。
- 补充数据存储、备份、迁移、隐私和故障恢复文档。

## 第三阶段：支持与发布制度

- 确定公开支持、商业集成和安全报告渠道。
- 建立 Stable / Beta / Preview 的版本分级。
- 建立 Changelog、兼容性、已知问题和弃用政策。
- 建立文档版本与产品版本的对应关系。

## 第四阶段：研究与工程证据

- 建立 ArduPilot SITL 基线和差异维护策略。
- 以 SeryRemoteID 完成安全、可靠、实时计算的第一组可复现实验。
- 逐步发布实验方法、数据摘要、失败边界和研究输出。
