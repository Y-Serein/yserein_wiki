# 获取支持

支持入口按问题类型分流。提交问题前，请准备产品名称、硬件版本、软件/固件版本、飞控平台、复现步骤和必要日志。

## 产品问题

### SeryRemoteID

- 功能问题与缺陷：[GitHub Issues](https://github.com/Y-Serein/SeryRemoteID/issues)
- 飞控集成：请注明 APM、PX4 或其他平台的具体型号和版本。
- 商业与批量集成：联系方式待维护者提供。

### Serein

- 功能问题与缺陷：[GitHub Issues](https://github.com/Y-Serein/Serein/issues)
- 安装、文件关联和 Windows 环境问题：请附系统版本、应用版本和复现步骤。

## 提交问题前

请至少提供：

1. 产品和版本。
2. 硬件型号、飞控平台或操作系统。
3. 预期行为与实际行为。
4. 最小复现步骤。
5. 日志、截图、抓包或错误信息；先移除密钥、身份和隐私数据。
6. 是否可以稳定复现。

## 安全问题

不要在公开 Issue 中直接提交可利用漏洞、私钥、签名材料或真实设备身份。

::: warning 私密报告渠道待配置
需要由维护者提供可公开的安全邮箱或其他私密渠道。配置完成前，本页面不能声称已经建立正式漏洞响应流程。
:::

## 文档反馈

文档问题可以提交到对应产品仓库，并在标题中使用 `docs:` 前缀。请指出页面 URL、错误内容和建议修改。
