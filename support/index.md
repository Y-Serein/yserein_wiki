# 支持与反馈

安装、产品使用、设备集成与授权问题可以通过以下入口获取帮助。先准备产品名称和实际版本，说明发生了什么，以及希望完成的操作。

## 软件版本获取 {#software-downloads}

Swarm、Scope 和 Serein 当前版本可通过 [支持邮箱](mailto:sereinc.y@gmail.com)联系获取。请说明产品、Windows 架构和所需组件。此入口用于获取软件和支持，不会自动完成账户授权或付款。

已有公开文件见[下载中心](/downloads/)。不要把仓库访问令牌或私人订阅链接用于公开分享安装器。

## 产品问题

- **Swarm**：说明网络连接、设备类型、目标数量、操作步骤与实际设备反馈。飞行中的紧急问题先按现场[应急流程](/products/swarm/emergency)处置，不等待在线支持。
- **Scope**：说明宿主与组件版本、设备/固件、连接方式及诊断信息。[组件常见问题](/products/scope/faq)可先定位。
- **Serein**：说明文档类型、编辑模式、操作系统和复现步骤。可通过 [GitHub Issues](https://github.com/Y-Serein/Serein/issues)提交非敏感问题。
- **SeryRemoteID**：说明硬件版本、飞控及固件版本；可通过 [GitHub Issues](https://github.com/Y-Serein/SeryRemoteID/issues)或支持邮箱联系。

## 提交问题前

1. 记录产品与实际版本、操作系统或硬件型号。
2. 写出预期行为、实际行为和最小复现步骤。
3. 提供脱敏截图、错误信息或最小文档副本。
4. 说明是否持续发生，以及重新连接后是否恢复。

## 私密与安全问题

私密问题通过 [支持邮箱](mailto:sereinc.y@gmail.com)先提供不含敏感材料的概要。不要在公开 Issue 中上传凭据、设备身份、个人 Vault 或可直接利用的漏洞细节。需要补充材料时再按约定提供；不承诺未约定的响应时间或 SLA。

## 文档反馈

请提供页面地址、错误描述与建议更正。也可向 [官网文档仓库](https://github.com/Y-Serein/yserein_wiki/issues)提交非敏感反馈。
